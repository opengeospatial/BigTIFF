== Media Types for any data encoding(s)
IANA defines the image/tiff media type for TIFF (https://www.iana.org/assignments/media-types/image/tiff). This Standard suggests the use of the same media type for BigTIFF, since it is a superset of TIFF. As a result, the media type image/tiff is used for both Classic TIFF and BigTIFF files.
In principle, clients do not need to negotiate with the servers between classic TIFF or BigTIFF. In fact, this kind of negotiation will enter in contradiction with the first recommendation in this Standards that states that servers and writers should only use BigTIFF for files bigger than 4 Gibibytes (2^32^) or when using the data types introduced in BigTIFF. Old clients not supporting BigTIFF will only receive BigTIFF when Classic TIFF will not work for them anyway.
Since a modern software is able to programmatically differentiate between a Classic TIFF and a BigTIFF, they can share the same media time for the BigTIFF.

This Standard is also suggesting that same file extension ('tif' or 'tiff') is used for both Classic TIF and BigTIFF, despite other previous proposals such as 'tf8' and 'btf' (discussed some time ago in the LibTiff mailing list).
